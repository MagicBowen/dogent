# General Document Template

## Introduction

Use this template when the user needs a professional document but has not selected a more specialized template.

Background:
- This is the default fallback template for Dogent document writing.
- It is intended to work across memos, reports, briefs, and general internal or external documents.

Precautions:
- Do not force a rigid structure when the user's requested document type clearly needs a different shape.
- Keep the final structure aligned with the user's audience and objective.

## Writing Requirements

- Start with a brief overview or context.
- Clarify the document goal and intended audience.
- Define terms on first use when necessary.
- Use a clear, logical structure with informative headings.
- Conclude with a concise summary or next steps.
- Keep sections balanced in length and scope.

## Output Guidance

Determine the final document structure according to the user's document type and specific needs.

Recommended baseline structure:
- Title
- Executive Summary or Overview
- Background
- Main Sections organized by topic, phase, workstream, or decision area
- Recommendations or Next Steps
- Appendix when supporting details would interrupt the main flow

Example adaptation for a short internal update:
- Overview
- Background
- Current Status
- Next Steps
