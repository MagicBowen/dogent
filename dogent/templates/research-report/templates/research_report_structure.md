# Research Report Structure

## Background / Context
- Define the problem, decision context, and key terms.

## Research Questions / Objectives
1. Primary question
2. Supporting questions

## Methodology
### Search Strategy
- Sources consulted
- Date range
- Example queries
- Inclusion and exclusion criteria

### Source Evaluation Approach
- Credibility checks
- Triangulation approach

### Limitations
- Gaps, constraints, or unavailable evidence

## Findings
- State each finding clearly.
- Attach evidence and citations directly to each finding.

## Analysis / Discussion
- Compare sources, explain disagreements, and discuss tradeoffs.

## Recommendations
- Action
- Expected benefit
- Risks / constraints
- Rationale and evidence

## Open Questions / Next Steps
- Remaining uncertainties
- What evidence would resolve them

## References
- Group sources if helpful, but ensure each cited item is real and accessible.
